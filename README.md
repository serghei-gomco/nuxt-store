# Quietfield Goods — Nuxt 3 storefront demo

A small, fast storefront built with **Nuxt 3**, TypeScript and Pinia. Fictional products, no real orders —
a personal portfolio project by Serghei Gomco. The goal was a fully static shop that scores 95+ in Lighthouse
(mobile) with zero layout shift; see [REPORT.md](REPORT.md) for the measurements.

- Catalogue grid with a category filter in the URL (`/?category=kitchen`)
- Product pages `/products/[slug]`, all prerendered
- Cart in Pinia, saved in `localStorage`, with no hydration mismatch and no header jump
- Local SVG images and the system font stack: no external requests at all

## Run

```bash
nvm use            # Node 22
npm install
npm run dev        # http://localhost:3000
npm test           # 13 unit tests: cart store + filter helper
npm run typecheck
npm run generate   # static site in .output/public (16 HTML files)
npm run preview    # serves .output/public on http://localhost:4173
npm run lighthouse # with preview running: Lighthouse mobile on home, a product page and the cart
```

## Structure

```
app.vue                        layout (header, demo notice, footer) + global CSS, inlined into the HTML
error.vue                      404 / error page
pages/index.vue                catalogue + category filter (?category=)
pages/products/[slug].vue      product page, 404 for unknown slugs
pages/cart.vue                 cart: quantity, remove, total
components/AppHeader.vue       logo + cart link with a fixed-size badge
components/ProductCard.vue     card in the grid
stores/cart.ts                 Pinia store: add / setQty / remove / clear / restore, count, total
plugins/cart-storage.client.ts reads the saved cart after mount, writes it back on every change
data/products.ts               12 fictional products and 4 categories (prices in cents)
utils/filter.ts                parseCategory, filterProducts, formatPrice (unit-tested)
public/images/*.svg            product illustrations, generated by scripts/generate-images.mjs
scripts/lighthouse.sh          the exact Lighthouse command used for REPORT.md
tests/                         Vitest
```

## Deploy to Vercel (static)

1. Push the repo to GitHub and import it in Vercel.
2. `vercel.json` already sets the build command to `npm run generate` and the output directory to
   `.output/public`, so Vercel serves plain static files — no serverless functions.

Any other static host works the same way: run `npm run generate` and upload `.output/public`.

## Notes

- The site is fully static, so the server never sees `?category=`. A direct visit to a filtered URL is handled
  without layout shift by a tiny inline script; details in [EXPLAIN.md](EXPLAIN.md) (Russian) and REPORT.md.
- There is no checkout: the cart only lives in the browser.
